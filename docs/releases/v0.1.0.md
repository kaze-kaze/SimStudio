# SimStudio 0.1.0 · Alpha

An auditable compiler and Codex Skill for ANSYS Mechanical linear static analysis.
Start with a reviewed specification, inspect the generated script, then explicitly execute and verify.

## In this release

- Deterministic, unit-aware YAML validation and Mechanical script generation. Dry-run remains the default.
- Explicit Windows `mechanical_batch` execution, structured status checks, and saved-process logs.
- Mechanical 2026 R1 compatibility fixes for scoping, template synchronization, Unicode, and independent DPF extraction.
- Bilingual documentation, three original Mechanical result images, a static demonstration, and hash-checked public evidence.

## What was actually tested

The September 6, 2026 benchmark recorded **9 passing cases across 5 real solves** with ANSYS Student
Mechanical 2026 R1 and the explicitly chosen batch backend. Cantilever tip Z displacement was
**−0.127583 mm**, **2.0664%** from the approximately 0.125 mm analytical reference, within the 15%
tolerance. Support Z resultant was approximately **1000 N**.

All five runs retain engineering status **WARN**. Stress-singularity review is pending, and safety
factor, automated visual review, mesh convergence, other Mechanical versions, and remote transport
were not validated. This installation's gRPC handshake failed; batch success does not resolve it.
The package and documentation checks performed at release time are offline and do not repeat the
historical solves.

The base CLI supports Python 3.11–3.13; optional ANSYS clients require Python 3.12–3.13. Mechanical
and a valid license must be provisioned separately for real execution. No ANSYS binaries, raw
solver archives, licensing diagnostics, or private local records are distributed.
