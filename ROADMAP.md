# Roadmap

## Implemented in the source tree; real acceptance pending

- Versioned, unit-aware studies for the controlled single-solid gusseted-bracket geometry: deterministic frozen samples, serial budget accounting, restart/recovery, mesh evidence, target-level dataset eligibility, reports, and portable task/results bundles.
- Safe JSON surrogate training, evaluation, and prediction; constrained candidate proposals and real-solve verification; an independent direct-search comparison using the study-wide solver-call allowance.
- Independent ansys-design-study Skill, bilingual user documentation, source/wheel distribution checks, and offline Linux/Windows Python 3.13 CI.

These source and offline-test capabilities do not constitute completed engineering acceptance. A complete Windows run with the intended build123d/font stack and licensed Mechanical installation, reviewed RST evidence, frozen holdout evaluation, candidate verification, and equal-budget comparison remains NOT_RUN. Do not infer model accuracy, mass reduction, or speed improvement before that evidence is recorded.

## Future directions

The following remain outside the current implementation and the ansys-mechanical-static / ansys-design-study Skills:

- steady-state thermal analysis
- modal analysis
- nonlinear static structural analysis
- Fluent CFD
- arbitrary geometry families beyond the controlled gusseted bracket
- PyWorkbench multi-system workflows
- a local security-hardened MCP server
- multi-node job queues
